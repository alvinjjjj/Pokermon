## 01 · 三大原則

### 1 · Precise 精準
給數字、給版本、給日期。形容詞最後才用。

**Rule of thumb**: 任何一句話如果可以加數字、年份、版本、百分比，就加。

| ✓ Do | × Don't |
|---|---|
| 「Charizard PSA 10 過去 30 日升 +12%」 | 「Charizard 卡升咗好多」 |
| 「2024 Pokémon Card 151 BOX 開出 5 張 EX」 | 「最近抽包好旺」 |
| 「個 PSA Population 由 124 升到 156」 | 「市面越來越多」 |
| 「2026/5/30 前申請 founding merchant 有 0 手續費」 | 「快啲嚟 join 我哋」 |

### 2 · Local 本地
**用港式中文。** 混雜英文 jargon 不避諱。香港藏家就係咁講嘢。

#### 允許的港式表達
- 「搵」「諗」「啱」「咁」「嚟」「嘅」「嗰」「呢個」「果個」
- 直接用英文：listing、portfolio、PSA、grade、population、market value、deal、chat、graded、raw card、JP、EN
- 數字 + 量詞：「兩張」「三隻」「一盒」「一箱」「一手」（一箱完整原封）
- HK 地名直寫：旺角、銅鑼灣、上環、灣仔、觀塘
- 港幣全部寫 **HK$** 或 **$HKD**（不要寫「港幣 XXX 元」太書面）

#### 中港用語對照（HKCardColl 用左邊）
| HK ✓ | TW / CN ✗ |
|---|---|
| 寵物小精靈 / Pokémon | 寶可夢 / 神奇寶貝（中文圈以外用）|
| 旺角卡店 | 西門町卡店 |
| 開包 / 開盒 | 拆卡 |
| 卡牌 | 卡片 |
| 收藏家 / 藏家 | 玩家 |
| listing | 商品頁 / 鏈接 |
| Deal / 成交 | 交易 |
| 認證商戶 | 認證商家 |

#### 但**正式文件**（投資人 deck、Privacy Policy、商標申請）用標準書面中文
日常 user-facing 文字（App、Push、IG）才用港式。

### 3 · Calm 克制
**不喊「驚喜」、不放鞭炮。** 價格起跌就是一個數字。Hype 留給市集，不留給介面。

#### 禁用語（一概不用）
- 驚喜！神奇！爆升！起飛！必入！
- 不要錯過！最後機會！僅此一次！
- 「！！」「！？」連用標點
- 🎉🔥💥🚀✨ 等 hype emoji（單個 ✓、⚠ 等 utility emoji 可以）
- 「老師」「大佬」等過分尊稱
- 「卷」「血賺」等流行語

#### 取而代之
| 想表達 | 應該怎麼寫 |
|---|---|
| 興奮 | 用數字代替形容（「+12%」「破 PSA 10 population 200」）|
| 推廣 | 給事實 + 截止日（「founding merchant 名額 10 個，5/30 截止」）|
| 慶祝 | 用 ✓ 符號或留白，不要 🎉 |
| 警告 | 用「注意」+ 解釋，不要 🚨 |

## 02 · 場景應用

### 推播 / Push Notification
**長度**：iOS 限 178 字、Android 限 65 字（顯示）。**真正讓人看的是前 40 字**。

**結構**：「【主體】【動詞 / 數字】【補充】」

| 場景 | ✓ Do | × Don't |
|---|---|---|
| 價格警示 | `Charizard ex (SV6a) JP +8% 過去 7 日，HK$ 6,400` | `🔥 你嘅卡升咗！快入嚟睇！` |
| 新 listing | `旺角 Mint 卡舖上架 12 張新卡，包括 PSA 10 Pikachu V-Union` | `🎉 有新卡上架啦！` |
| 訊息 | `Alex 對你 Charizard PSA 9 出 HK$ 4,800` | `🔔 有人 chat 你！` |
| 系統 | `Apple Sign In 已綁定 · 設定 → 帳號可解除` | `成功！🎉 你已綁定 Apple ID` |

### IG / 小紅書 Caption
**結構**：
1. **第一句 = hook**（一個數字 + 一個事實）
2. **中段 = 解釋 + 數據**
3. **結尾 = call to action（克制，給選擇）**

**範例**：
```
旺角 Mint Card 上架第一張 PSA 10 Pikachu V-Union (SWSH286)。

近 30 日 HK 區 PSA 10 成交價：
· 2025-12  HK$ 18,400
· 2026-02  HK$ 21,000
· 2026-04  HK$ 23,500

#HKCardColl #PokemonTCG #VUnion #PSA10

App 內 listing → 點 bio link
```

#### 不要：
```
🎉🔥 爆貨！PSA 10 Pikachu V-Union 來了！！！
史詩級神卡！手快有手慢冇！全港最低價！
⚡⚡⚡ 即刻入嚟 ⚡⚡⚡
#旺角 #香港 #pokemon #發財 #必入
```

### Email（給商戶 / 投資人）
**結構**：
1. 主旨：精準描述目的 + 一個數字
2. 第一句：你是誰 + 為什麼寫這封信
3. 中段：3 個 bullet 講重點
4. 結尾：明確 ask + 截止日

**主旨範例**：
- ✓ `HKCardColl 認證商戶邀請 · founding 名額 10/10 待定`
- ✗ `合作邀請 🎉🎉🎉 機會難得！`

### 客服 / 系統訊息
**規則**：
1. 不道歉超過 1 次
2. 不用「親」「您」連續用（一句一個就夠）
3. 給時間估算

| 場景 | ✓ Do | × Don't |
|---|---|---|
| 錯誤 | `驗證失敗。請重新輸入 OTP（最多 5 次嘗試）。` | `哎呀！出錯了 😭 親請再試一次` |
| 處理中 | `審核中。一般 1-2 個工作天回覆。` | `我哋會盡快為您處理！🙏` |
| 成功 | `Listing 已上架 · 24 小時內顯示在搜尋結果` | `恭喜成功！🎉 大家可以看到了` |

### 投資人 / 對外 Pitch
**規則**：
- 用標準書面中文 + 英文對照（雙語 deck）
- 數字必須**有對照基準**（不是 +12%，是 vs 過去 30 日 +12%）
- 引用一定加來源（不是「市場數據」，是「Pokemon Price Tracker 2026-04」）
- 避免 buzzword（avoid: AI-powered、disruption、game-changing、revolutionary）
- 保留 buzzword（OK: real-time、cross-platform、verified）

## 03 · 4 個 Manifesto 原則

來自 Brand Book Vol.01 · 01 / MANIFESTO

| # | 原則 | 在文字裡的意思 |
|---|---|---|
| 01 | **Catalogue first** | 先記錄、再評論。先講事實，再有觀點 |
| 02 | **Trust the grade** | PSA / BGS 為準，主觀為輔。引用權威評級數字 |
| 03 | **Local lens, global price** | 港視角、全球行情。HKD 為基準，但展示 JP / EN 原始價 |
| 04 | **Trade with proof** | 換卡留下證據。任何承諾要有 reference |

## 04 · 快速 Checklist（出文前自查）

寫完任何 user-facing 文字，**逐項自問**：

- [ ] 第一句有沒有具體**數字 / 版本 / 日期**？
- [ ] 有沒有用「！」連發 / hype emoji？→ 刪
- [ ] 有沒有用「驚喜 / 爆升 / 必入 / 起飛」？→ 換成數字
- [ ] 港式中文 vs 書面中文，是否符合該場景？
- [ ] 引用的數字 / 比例**有出處**嗎？
- [ ] 有 CTA 的話，是給選擇還是 push hard sell？應該給選擇

如果以上任何一項答「沒/不對」，**重寫**。

## 05 · 範本庫（直接複製改）

### 範本 A · 價格警示推播
```
[卡名] [版本] [幣別] [變化%]，[時段]，現價 HK$ [當前價]
```
範例：`Charizard ex (SV6a) JP +8%，過去 7 日，現價 HK$ 6,400`

### 範本 B · 商戶招募 IG 帖
```
[地點] [店名] 已成為 HKCardColl founding merchant。

[3 個事實 bullet]
· [事實 1]
· [事實 2]
· [事實 3]

founding 名額剩 [N] 個 · [截止日期]
申請 → bio link
```

### 範本 C · 開箱社群帖
```
[卡盒名稱] [版本] 開箱結果

[N] 包 · 抽到 [簡述]
亮點：
· [卡 1] [評級 / 估值]
· [卡 2] [評級 / 估值]

完整作品集 → app 內個人頁
```

### 範本 D · 系統 email（用戶導向）
主旨：`[動作完成] · [關鍵資訊]`
範例：`Listing 已審核 · 24 小時內上架`

正文：
```
[一句說明發生什麼事，含時間]

[1-2 句解釋下一步]

[明確 ask 或 link]

— HKCardColl
```

## 06 · 例外情況

### 何時可以打破規則？
- **404 / 趣味彩蛋頁**：可以稍微幽默
- **農曆新年 / 重大節日推送**：可以一句口頭祝賀（仍然不用 emoji）
- **付費用戶的私人歡迎信**：可以稍微暖一點

但任何例外**必須在 HKCC · Command 對話確認**，不能 ad-hoc 自己決定。
