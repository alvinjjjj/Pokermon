The Brand

Collectr Orange is the single brand color. It signals action, energy, and the warmth of a card-collector community. Used 329 times across the current codebase — already the de-facto identity. We formalize it.

Usage Rules

Do
  • Reference tokens from constants/colors.ts only.
  • Use semantic role names (success, danger), not literal colors.
  • Pair text and surface tokens (text/primary on surface/base).
  • Default new users to Light Mode. Save preference per device.
  • Brand primary is the single accent — resist adding more.
  • Keep #B40000 JP-flag red as data color, not theme.
Don't
  • Hardcode hex codes in new JSX. Use the theme hook.
  • Use pure black (#000) or pure white (#FFF) for text in dark mode.
  • Introduce new accent colors without team review.
  • Use the same hex for light and dark — they must be paired tokens.
  • Use useColorScheme() directly — read from theme context.
  • Mix tints across modes (e.g. light tint on dark bg).

Implementation Notes

Bridge from this brand book to working code.

File structure
constants/colors.ts — exports lightColors, darkColors, and ColorTokens type
theme/ThemeProvider.tsx — context wrapping the app, persists choice via AsyncStorage
theme/useTheme.ts — hook returning { colors, mode, setMode }
app/_layout.tsx — wrap root in ThemeProvider, conditional StatusBar
app/(tabs)/settings.tsx — add Appearance row: Light · Dark · System

Default behavior
First launch / fresh login → Light Mode (per spec).
User pick persists across sessions (AsyncStorage key: theme_mode).
"System" option later — follows iOS/Android system preference.

Refactor strategy
Phase 1 — Ship theme infrastructure + settings toggle. Tokens exist, hook works, but screens still use hex.
Phase 2 — Refactor hot spots first: shops.tsx, search.tsx, card/[id].tsx, index.tsx.
Phase 3 — Refactor remaining screens incrementally. Use grep #[0-9a-fA-F] to track progress.
Phase 4 — Lint rule blocking new hex codes in JSX.

WCAG status
All text tokens AA or better against their paired surface. Disabled text intentionally fails — decorative use only, never carry meaning.
Brand orange (#FF6900) does not meet AA on white for small text — use only for buttons/accents with text-inverse (white) on top.
