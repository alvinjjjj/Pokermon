# /collectr/notes/ — 對話精華區

這個資料夾保存所有從舊 Cowork 對話**提取出來的精華**。

## 為什麼存在
Cowork 每個 chat 是**獨立的**——新 chat 看不到任何其他 chat 的歷史。要保留價值，必須在刪除前先把精華寫入這裡，新 chat 才能引用。

## 命名規則
`[領域]_[主題]_[日期].md`

例：
- `growth_competitor-research_2026-05.md`
- `ux_user-interviews-batch1_2026-05.md`
- `numbers_seed-fundraising-plan_2026-05.md`

## 怎麼讓新對話讀這裡
任何新 chat 開頭貼：
```
請先讀 /Users/alvin/collectr/product.md 和 /Users/alvin/collectr/notes/ 內所有檔案，
之後以此為脈絡。本對話專責 [growth / product / code / numbers / command]。
```

詳細遷移流程見 [`chat-migration-sop.md`](./chat-migration-sop.md)
