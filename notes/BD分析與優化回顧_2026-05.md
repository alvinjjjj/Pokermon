## 核心決策

### 產品定位
- App 名稱：**Collectr**（對外）/ **HKCARDCOLL**（商家規格文件內）
- 核心定位：香港 Pokemon 卡牌收藏家的 all-in-one 平台
- Tech Stack：React Native (Expo) + Supabase + Expo Router

### 用戶三層架構（已確定）
| Tier | 類型 | 上傳限制 | 認證 | 計入 HK Price DB |
|------|------|---------|------|----------------|
| 0 | Viewer | 10 張 | ❌ | ❌ |
| 1 | Individual Seller | 10 張 | 自申報 | ❌ |
| 2 | Certified Merchant | 100 張 | BR 文件 | ✅ |

### 競爭護城河（已識別，共識）
1. **HK Market Price DB** — 只有認證商家定價計入，scraper 無法複製
2. **BR 驗證商家信任體系** — 香港唯一
3. **JP + EN 雙語價格**（PPT API + artofpkm + TCGdex）
4. **JP Promo 卡圖片**（XY-P / SM-P / SV-P 系列，其他 app 做不到）
5. **封箱價格 DB**（boosterBoxes.ts + Excel 表）
6. **社群 + 收藏 Portfolio tracking**

### 市場擴張方向（已確定，i18n 已建好）
- 主力：🇭🇰 香港（zh-HK）
- 次要：🇹🇼 台灣 / 馬來西亞 / 新加坡（zh-CN）
- 進攻：🇯🇵 日本（ja）— 連內容（JP promo 圖）都做好才加語言，方向正確
- 長線：🇺🇸 英語市場（en）

### 技術安全決策（已確定）
- PPT API key 透過 Supabase Edge Function proxy（`ppt-proxy`），永不進 JS bundle
- Admin 全部操作走 SECURITY DEFINER RPC，非 admin throw forbidden
- PSA_MULT 假估算已移除，無真實數據時顯示 "price pending"
